# G-Code Assistant 2027

Official downloads and updates for G-Code Assistant Electron.

官方安装包与更新说明。此仓库仅存放发布文件，源码位于独立私有仓库。

## 下载 / Downloads

请打开 [Releases](https://github.com/Canary1113/G-Code-Assistant-Releases/releases)：

- Setup EXE：安装版，下载后运行安装。
- ZIP：便携版，解压后运行 G-Code-Assistant.exe。

## 更新频道 / Update channels

- **Release**：稳定版，构建号末位为 9，测试完成后发布。
- **Beta**：测试版，构建号末位为 5，提前体验新功能，可能遇到问题。

软件的“更新与关于”页面按所选频道检查新版本。自动检查更新默认关闭。
