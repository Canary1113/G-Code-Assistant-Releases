# G-Code Assistant 2027

🛠️ A Windows desktop companion for editing, reviewing, and visualizing CNC programs.

G-Code Assistant brings everyday programming tools into one workspace, helping you inspect code, prepare coordinate changes, compare revisions, and keep useful references close at hand.

## ✨ Features

- **Code editing:** syntax highlighting, line numbering, search and replace, program navigation, and configurable completion.
- **Coordinate tools:** translation, rotation, axis swaps, and sign changes with an editable preview before applying results.
- **Toolpath visualization:** inspect supported movements and coordinate systems through trajectory playback and rotation diagrams.
- **Code comparison:** review differences between two programs with highlighted changes and synchronized views.
- **Reusable commands:** organize templates and configurable checking rules for repeated programming tasks.
- **Quick Reference:** keep PDF manuals and Markdown notes alongside your code, and add your own reference files.
- **Personalization:** light and dark themes, accent colors, interface effects, user profiles, and support for English, German, Simplified Chinese, and Traditional Chinese.

## 📥 Download

Get the Windows installer or portable ZIP from [Releases](https://github.com/Canary1113/G-Code-Assistant-Releases/releases).

- **Installer:** run the Setup EXE and follow the installation steps.
- **Portable:** extract the ZIP and launch `G-Code-Assistant.exe`.

## 🔄 Updates

Open **Settings → Updates and about** to check for newer versions and choose a download.

- **Release:** tested releases intended for everyday use.
- **Beta:** earlier access to new features and improvements; some behavior may still change.

Automatic update checks are optional and disabled by default.
